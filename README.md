# Mobile Banking PWA Lab

An Angular 22 learning project for building and explaining a mobile-first Persian banking simulator. The two main features are a simulated internal transfer with a receipt and a spending report built from synthetic transactions. The learner owns the implementation and uses mentoring for questions, hints, and code review.

**Current milestone:** phase 0, browser JavaScript and TypeScript. This repository currently contains the project brief and learning materials.

## پروژه

یک وب‌اپ نصب‌شدنی و موبایل‌محور با رابط فارسی، راست‌چین و طراحی مستقل. صفحهٔ خانه، موجودی و گردش حساب نمایشی را نشان می‌دهد. دو قابلیت اصلی برای دمو داریم:

1. **انتقال داخلی شبیه‌سازی‌شده** با انتخاب مقصد، ورود مبلغ، تأیید و رسید. سناریوهای خطا و نتیجهٔ نامعلوم هم بخشی از تمرین‌اند.
2. **گزارش مخارج** با فیلتر زمانی و دسته‌بندی، جمع هزینه و جزئیات تراکنش‌های هر دسته.

تمام حساب‌ها، مبالغ و تراکنش‌ها ساختگی‌اند. محصول برای تمرین فرانت‌اند یک تیم PWA طراحی شده است. کیفیت مورد انتظار شامل توضیح تصمیم‌های فنی، نمایش سناریوهای شکست، تست و یک دموی قابل تکرار است.
